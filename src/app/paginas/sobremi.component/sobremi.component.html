Sobre mí

Espartinas, Sevilla

Soy Daniel, desarrollador especializado en la construcción de soluciones multiplataforma y web completas. Cuento con titulación en Desarrollo de Aplicaciones Multiplataforma (DAM) y base técnica previa en Sistemas Microinformáticos y Redes (SMR).

Mi trabajo combina la creación de interfaces orientadas a la experiencia de usuario con arquitecturas backend fiables: consumo y diseño de APIs REST, persistencia de datos relacionales y móviles, y despliegues optimizados.

Backend & Datos Spring Boot, SQL & Firebase
Frontend Web Angular Standalone & CSS
Nativo Móvil Android Studio & Kotlin
